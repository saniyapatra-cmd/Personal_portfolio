# Saniya Patra — Personal Portfolio

A responsive personal portfolio website for Saniya Patra, a B.Tech Information Technology undergraduate at Narula Institute of Technology.

## Run locally
Open `index.html` in a modern browser. The site uses Google Fonts and Ionicons from CDNs, so those assets require an internet connection.

## Sections
- Introduction and About
- Skills & Toolkit
- Education
- Selected projects
- Contact details and social profiles

## Project status
The Portfolio Website is the current portfolio project. JARVIS Voice Assistant, ShopSphere E-commerce, DSA Visualizer, and CareerCompass AI are presented as planned projects/concepts, not completed work.
